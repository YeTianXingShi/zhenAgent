# UI 组件库调研

- 日期：2026-10-10
- 状态：已完成

## 调研问题

寻找 GitHub star 超过 10,000 的开源 React UI 组件库，供本项目接入时选择。本轮只调研，不安装依赖或修改前端。

## 来源与发现

以下数字来自本次查阅的 GitHub 页面，是页面显示的约数，会随时间变化。适用场景属于本项目的选型判断，未经过接入验证。

| 仓库 | Star 约数 | 特点与项目适用场景 |
| --- | --- | --- |
| [shadcn/ui](https://github.com/shadcn-ui/ui) | 125,200 | 组件源码可定制，适合定制聊天工作台；需自行维护引入的源码。 |
| [Ant Design](https://github.com/ant-design/ant-design) | 99,700 | 企业应用 React 组件库，适合设置页、表单与数据管理界面。 |
| [Material UI](https://github.com/mui/material-ui) | 99,200 | Material Design React 组件库，适合接受该视觉体系的应用。 |
| [Chakra UI](https://github.com/chakra-ui/chakra-ui) | 40,700 | 面向 SaaS 的组件系统，可作为工作台候选。 |
| [Mantine](https://github.com/mantinedev/mantine) | 31,800 | 包含基础组件、hooks、表单和通知等包，适合快速补齐工作台控件。 |
| [Radix Primitives](https://github.com/radix-ui/primitives) | 19,400 | 面向可访问性与设计系统的基础组件，适合保留自有外观时使用。 |

[shadcn 的 Vite 接入文档](https://ui.shadcn.com/docs/installation/vite)提供 React/TypeScript 接入步骤，包括 Tailwind CSS 和路径别名。[Mantine 入门文档](https://mantine.dev/getting-started/)提供 Vite 指引及各功能包说明。

另外查阅了 [Ant Design X](https://github.com/ant-design/x)，页面显示约 4,800 star。它面向 AI 界面，但不满足本次门槛；不能用 Ant Design 主仓库的 star 替代它自身的数字。

## 对本项目的影响

本地依据：`frontend/package.json` 使用 React 19、TypeScript、Vite 和 pnpm，尚未引入 UI 库或 Tailwind；`frontend/src/App.tsx`、`Settings.tsx`、`Reasoning.tsx`、`FilePreview.tsx` 与 `styles.css` 实现聊天、设置、思考折叠和文件预览。

优先考虑 shadcn/ui 和 Mantine。若目标是定制 agent 工作台外观，优先 shadcn/ui；若目标是减少表单、弹窗和通知的开发工作，优先 Mantine。这是基于当前界面和官方文档的判断，不是性能测量结论。

接入时先处理按钮、设置表单和弹窗，再考虑聊天区。思考文本、工具审批和文件差异属于业务展示，基础 UI 库不能直接替代其业务逻辑。正式接入前核对所选版本的 React peer dependencies、许可证及样式影响。
