## 调研问题

OpenCode 接入 DeepSeek 时，模型名称、接口地址、上下文上限、能力与调用参数分别从哪里获取。

## 模型目录来源

OpenCode 使用 Models.dev 模型目录。这个版本默认获取 `https://models.opencode.ai/api.json`，可以用 `OPENCODE_MODELS_URL` 替换目录服务地址。源码中的请求是获取公共模型目录，不是向 DeepSeek 查询账户可用模型。[目录地址与请求](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/core/src/models-dev.ts#L160-L181)

Models.dev 是公开的模型规格、价格和功能数据库，上游按 provider 和模型维护 TOML 文件。查阅当天，DeepSeek 的 provider 文件记录 `npm = "@ai-sdk/openai-compatible"`、`api = "https://api.deepseek.com"` 和 `env = ["DEEPSEEK_API_KEY"]`；模型文件位于 `providers/deepseek/models`。这说明这些目录信息来自 Models.dev 维护的数据；不能因此声称所有数值都由 DeepSeek 接口动态返回。[Models.dev 使用与维护说明](https://models.dev/)，[DeepSeek provider 文件](https://github.com/anomalyco/models.dev/blob/dev/providers/deepseek/provider.toml)，[模型文件目录](https://github.com/anomalyco/models.dev/tree/dev/providers/deepseek/models)

目录包括 provider 的 `api`、`npm`、`env`，以及模型的名称、价格、上下文与输出上限、输入输出模态、工具调用与推理能力。`temperature` 在目录 schema 中是布尔值，表示模型是否支持温度参数，不是温度默认数值。[目录字段](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/core/src/models-dev.ts#L67-L129)

Provider 将这些字段转换成自己的模型对象；接口地址优先取模型级 `provider.api`，再取 provider 级 `api`，能力和上限从目录复制。普通模型的 `options` 初始为空，所以目录元数据不等于每次调用的全部默认参数。目录的 `experimental.modes` 还可以提供特定模式的请求 body 和 headers。[模型转换](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/provider/provider.ts#L1316-L1387)

## 快照、缓存与刷新

加载顺序是：

1. 读取 `OPENCODE_MODELS_PATH` 指定的文件；未指定时读取本地缓存。
2. 文件读取没有得到数据时，读取构建时嵌入的 `OPENCODE_MODELS_DEV` 快照。
3. 没有快照时获取远程目录并写入缓存；若设置了 `OPENCODE_DISABLE_MODELS_FETCH`，这一步返回空目录。

指定本地路径会替代缓存文件的读取位置；该文件读不到数据时仍会继续尝试快照。缓存存放在 `Global.Path.cache`，默认文件名为 `models.json`；自定义目录地址使用包含地址哈希的文件名。[文件与快照加载顺序](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/core/src/models-dev.ts#L160-L231)，[缓存根目录](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/core/src/global.ts#L10-L28)

构建脚本先从目录服务获取 JSON，也可以用 `MODELS_DEV_API_JSON` 指定已有 JSON 文件；随后通过 Bun 的 `define` 把原始 JSON 嵌入二进制。这使安装包在首次获取远程目录前也有模型数据。[构建时获取目录](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/cli/script/generate.ts#L1-L7)，[嵌入快照](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/cli/script/build.ts#L84-L89)

启动目录服务时会在后台尝试刷新，此后每 60 分钟再次尝试。缓存修改时间在 5 分钟内则跳过普通刷新；强制刷新可以绕过这一判断。刷新成功后替换缓存、清除内存读取结果并发布更新事件；刷新失败记录错误并忽略，不在此处删除已有目录。`OPENCODE_DISABLE_MODELS_FETCH` 会关闭这项后台刷新，但保留文件和快照读取。[缓存时效](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/core/src/models-dev.ts#L165-L173)，[刷新处理](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/core/src/models-dev.ts#L237-L258)

## 运行时请求参数

调用参数由 OpenCode 的 ProviderTransform、模型配置、agent 配置和选中的 variant 共同产生。模型专用 options 的合并顺序是 ProviderTransform 基础值 → `model.options` → `agent.options` → 选中的 variant，后面的值覆盖前面的值；随后插件的 `chat.params` 还能修改参数。这条路径没有统一从 DeepSeek 拉取全部参数默认值的步骤。[options 合并](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/session/llm/request.ts#L80-L91)，[调用参数与插件入口](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/session/llm/request.ts#L114-L131)

| 参数 | 本版本的来源与行为 |
| --- | --- |
| `temperature` | 模型支持温度时，优先取 agent 的配置，再取 ProviderTransform；该函数没有 DeepSeek 专用默认数值，通常返回 `undefined`。[温度逻辑](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/provider/transform.ts#L530-L547) |
| `topP` | 优先取 agent 配置。ProviderTransform 对特定 `deepseek-v4-flash` 名称和 provider 条件返回 `0.95`，不适用于所有 DeepSeek 模型。[采样逻辑](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/provider/transform.ts#L549-L562) |
| 输出 token 上限 | 取目录的 `model.limit.output` 与 OpenCode 输出上限中较小者。OpenCode 默认上限为 `32_000`，可由 `OPENCODE_EXPERIMENTAL_OUTPUT_TOKEN_MAX` 调整。[默认常量](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/provider/transform.ts#L18)，[上限计算](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/provider/transform.ts#L1481-L1483)，[环境变量](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/effect/runtime-flags.ts#L52) |
| 推理档位 | 优先根据目录的 `reasoning_options` 生成可选 variants，缺少该字段时使用 ProviderTransform 的兼容规则。生成了 `high` 等选项并不等于默认选中该档位；调用时读取用户选中的 variant。[variants 来源](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/provider/provider.ts#L1365-L1369)，[推理元数据转换](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/provider/transform.ts#L1717-L1746)，[选择条件](https://github.com/anomalyco/opencode/blob/055d95bb7e278c94baf06235a52cac79dd13ba67/packages/opencode/src/session/llm/request.ts#L80-L83) |

应分别看待目录中的能力与上限、OpenCode 选择的请求参数，以及参数未发送时由模型服务采用的行为。本次没有请求 DeepSeek，不核定其服务端默认值。

## 对本项目的影响

模型目录可用于提供服务地址、模型列表、能力、价格和上限等初始信息。请求参数仍需单独定义来源和覆盖顺序；尤其不能把目录中的 `temperature: true` 当成请求的温度值。

本次只调研来源，不修改 zhenAgent 的模型配置或调用行为。
