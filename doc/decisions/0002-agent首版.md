# 0002：agent 首版

- 日期：2026-10-10
- 状态：已接受

## 决策

采用 FastAPI 后端和 React/TypeScript/Vite 前端，首个目标为 DeepSeek `deepseek-flash` 的 Responses 接口。使用原始 JSON 传输，保留推理 items 与服务扩展字段。先完成本机单人通用工具 agent。

使用 SQLite 保存会话、任务与事件；用本地 `0600` 文件保存密钥。服务和模型由 Web UI 配置，每个会话固定二者。多个会话共用一个工作目录，全局只运行一个任务。

只读自动执行，写入和命令逐次审批；拒绝结束任务。任务与页面连接独立，后端重启后不续跑。模型失败可受限重试，工具执行与模型请求重试分开。

用户负责手动验证和测试用例，本轮不创建或执行测试用例。工具链与代码骨架在此决策中确定，补充初始化决策留下的事项。

## 备选方案与取舍

- TUI、Node.js 业务中间层：用户选择 Web UI 和 Python 业务接口。
- Chat Completions、同时支持两种协议：用户选择 Responses。
- 容器执行、并行会话任务：用户选择本机审批执行和全局单任务。
- 默认加载 AGENTS.md 与 skill：用户选择首版只用内置指令。
- 自动测试和假模型服务：用户选择自行验证及编写测试用例。

## 影响

命令保留本机权限，工作目录不是沙箱。公开仓库只保存代码与正式文档；密钥、会话及模型输出保留在 `.local`。其他 Responses 服务的实际兼容性需配置后验证。
