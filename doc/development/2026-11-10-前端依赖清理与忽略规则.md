# 前端依赖清理与忽略规则

- 日期：2026-11-10
- 状态：已完成
- 分支：`chore/gitignore-pnpm-vite`

## 问题与目标

本机运行 `scripts/start.sh` 启动前端服务时，因 `frontend/node_modules` 尚未安装且 pnpm 默认在运行脚本前执行 `verify-deps-before-run` 检查，pnpm 向上查找工作区命中了用户主目录 `~` 下残留的 `pnpm-workspace.yaml`，转而对主目录执行 `pnpm install` 并因未批准构建脚本报错退出（`ERR_PNPM_IGNORED_BUILDS`）。

本次清理主目录残留的 Node.js 项目文件、安装 `frontend` 依赖，并补充仓库 `.gitignore` 对 pnpm 与 Vite 产物及日志的忽略规则。

## 实际改动

1. 清理主目录 `~` 下残留的 `pnpm-workspace.yaml`、`pnpm-lock.yaml`、`package.json`、`package-lock.json`、`bun.lock` 和 `node_modules`，解除对 `frontend` 的工作区劫持。
2. 执行 `pnpm --dir frontend install --frozen-lockfile`，按 `frontend/pnpm-lock.yaml` 安装前端依赖并生成 `frontend/node_modules`。
3. 核对并更新 [`.gitignore`](../../.gitignore)，在原有 `/.local/`、`.env`、`.env.*`（保留示例文件）、`node_modules/`、`/frontend/dist/`、`/workspace/`、`.venv/` 等规则基础上，补充 `.pnpm/`、`pnpm-debug.log*`、`.pnpm-debug.log*`、`npm-debug.log*`、`.vite/` 与 `vite.config.*.timestamp-*`。

## 验证

1. Git 忽略规则检查：运行 `git check-ignore -v` 核对 `.env`、`frontend/.env`、`frontend/.env.local`、`.local/logs/frontend.log`、`.local/run/frontend.pid`、`frontend/node_modules`、`frontend/dist/`、`workspace/`、`backend/.venv`、`pnpm-debug.log`、`.pnpm-debug.log`、`.pnpm/`、`frontend/.vite/`、`frontend/vite.config.ts.timestamp-0.mjs`，均正确命中忽略规则；`git status -sb` 仅显示本次任务改动。
2. 前端类型检查与构建：运行 `pnpm --dir frontend build`（`tsc --noEmit && vite build`），通过。
3. 后端与脚本语法检查：运行 `uv run --project backend --locked python -m compileall -q backend/src` 与 `bash -n scripts/*.sh *.sh`，均通过。
4. 文档链接与提交差异检查：核对本次新增及修改文档的本地相对链接存在，运行 `git diff --cached --check` 无格式错误。
5. 功能与服务启动验证：按项目约定未编写或运行测试用例、功能测试与真实模型联调，前端后台启动由用户自行验证。
