## 目标与关联文档

用户选择 shadcn/ui 作为本项目的基础 UI 组件。依据见 [组件库调研](../research/2026-10-10-ui组件库.md)，比较条件见 [消融计划](../experiments/2026-10-10-ui组件接入消融计划.md)。

## 实际改动

- 配置 Tailwind 4 Vite 插件、TypeScript/Vite 的 `@` 别名和 `components.json`，组件源码存入 `frontend/src/components/ui`。
- 使用官方 Button、Input、Textarea、NativeSelect 替换会话、审批和设置页的基础控件。NativeSelect 保留原生表单值、required 校验与 change 事件。
- 设置和新建会话使用 Dialog，提供标题、说明、关闭按钮与关闭后的焦点恢复；设置页使用 Tabs。
- 沿用绿色主题和现有布局。只引入 Tailwind theme 与 utilities，不启用 Preflight，以免重置现有 Markdown 等页面内容的默认样式。
- 保留聊天、思考、文件预览及后端业务逻辑，锁定新增依赖，并补充 [第三方来源](../../THIRD_PARTY.md) 和 MIT 许可证。

官方 CLI 在安装子进程中未沿用项目的 pnpm store，安装失败。实际从官方 registry 下载源码，手动安装其所需依赖。项目本机使用 `.local/pnpm-store`，本轮安装命令显式传入 `--store-dir ../.local/pnpm-store`；没有修改全局 pnpm 配置。

参考源码：`~/zhenProject/opencode/packages/ui/src/components/dialog.tsx`。该文件使用 Solid/Kobalte 把标题、说明、关闭按钮和内容封装在 Dialog 中。本项目只参考封装边界，使用 React/shadcn/Radix 实现，未复制其源码。
