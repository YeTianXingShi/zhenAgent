# agent 首版

- 日期：2026-10-10
- 状态：已确认

## 目标与范围

实现本机单人使用的 Web 通用工具 agent。Python 提供业务接口，Node.js 工具链构建 React/TypeScript 前端，前后端独立运行。首个模型为 DeepSeek `deepseek-flash`，只接入 Responses 协议。

- Web UI 管理多个服务及模型、创建和切换会话；每个会话固定服务和模型。
- 后端用 SQLite 保存消息、原始 Responses items、任务状态、工具结果和事件。API key 在 `.local` 的权限为 `0600` 的文件中保存，查询接口不回显。
- 启动时配置一个工作目录。提供列目录、读取、搜索、写入、编辑和命令执行工具。文件工具限制在工作目录内；命令审批后在本机执行，工作目录不是沙箱。
- 读取和搜索自动执行，写入、编辑和命令逐次审批。拒绝审批结束任务。
- 刷新或关闭页面后任务继续；停止按钮取消任务。后端重启将未结束任务标为中断，保存已有结果，不自动续跑。
- 全局同时只执行一个任务。默认最多 20 次模型调用，命令超时 120 秒，限制输出大小。
- 模型请求失败最多额外重试 2 次，等待 1 秒、2 秒，计入调用预算。网络错误、超时、限流和服务端错误可重试；认证及参数错误直接结束。
- 流中断可重试，失败尝试保留在界面，原始不完整输出不进入模型上下文；完整响应后才执行工具。已完成的工具结果持久保存，重试不重跑整个任务。
- 默认思考强度为 `high`，可选 `none`、`low`、`high`、`max`。界面显示正文和工具过程，推理项由后端保存、回传。
- 工具错误与命令非零退出回传模型，允许其在剩余预算内处理。

首版只用内置指令。AGENTS.md、运行时 skill、MCP、子 agent、长期记忆、网页浏览和图片附件后置。
