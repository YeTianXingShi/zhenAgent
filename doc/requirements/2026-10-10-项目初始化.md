## 目标

## 本次范围

- 将项目规则入口改为 `AGENTS.md`，保留参考项目、消融实验和 shuorenhua 加载要求。
- 建立六类开发文档及索引、说明和模板，保存本次初始化选择。
- 初始化本地 Git 和 `main` 分支，创建公开的 `YeTianXingShi/zhenAgent` 仓库并推送。
- 使用英文类型标记加中文说明的约定式提交，提供提交模板，先通过人工核对执行规则。
- 完整追踪 shuorenhua 安装目录，保留其来源和许可证。
- 添加忽略规则、编辑器配置和本项目 MIT 许可证。

代码骨架、两种语言的职责、工具链、运行时版本、测试框架和 CI 在首个功能设计时确定。

## 验收标准

- 原有项目规则保留，文档索引和相对链接可用，各分类可直接新增记录。
- 项目文件与完整 skill 被 Git 追踪；私人材料、环境配置和生成产物被忽略。
- 首次提交使用 `chore: 初始化项目文档与开发规范`，差异检查通过，工作区干净。
- GitHub 仓库公开，默认分支为 `main`，上游关联建立，远程和本地提交一致。
- 远程操作失败时保留本地成果，明确记录阻塞情况。
