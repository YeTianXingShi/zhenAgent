# 服务管理脚本需求

- 日期：2026-11-10
- 状态：已确认

## 问题与目标

zhenAgent 包含 FastAPI 后端和 Vite 前端两个独立进程。目前启动服务需要分别在两个终端手动执行长命令，停止服务需要手动中断终端或查找进程终止，缺少统一的启动、停止与重启控制脚本。

目标是提供一套服务管理脚本，实现后端与前端的一键启动、后台运行、停止与重启，并提供就绪检测与状态提示。

## 本次范围

1. 新增三个管理脚本：
   - 启动脚本：后台启动后端与前端，记录 PID，输出日志文件位置，等待服务就绪并提示访问地址。
   - 停止脚本：读取 PID 并终止对应进程树（包括父子进程），清理 PID 记录。
   - 重启脚本：依次执行停止与启动。
2. 支持单独操作指定服务（如仅启动后端或前端）或默认操作全部服务。
3. 提供状态查看与端口/进程冲突检测。
4. 提供项目根目录快捷入口及 `scripts/` 目录组织。
5. 更新使用说明与文档索引。

## 验收标准

1. 根目录与 `scripts/` 下均提供可执行的启动、停止和重启脚本。
2. 启动脚本能后台拉起后端与前端，将 PID 写入 `.local/run/`，日志输出至 `.local/logs/`，并进行就绪检查。
3. 停止脚本能正常停止指定或全部服务，连带清理子进程，不遗留孤儿进程占用端口。
4. 重启脚本在服务运行或未运行时均能可靠完成重启。
5. 脚本具备缺失依赖（`uv`、`pnpm`）与配置文件（`.env`）的基础检查与提示。
6. 完成语法检查，更新使用文档与文档索引。

## 需求变更

- 2026-11-10：用户要求服务同时监听本地 IP 和当前设备在局域网的 IP，并在启动记录（日志与控制台）中展示局域网访问地址。后端放宽私有局域网跨域与主机检查，前端支持自适应主机名请求后端。
